# Landmark Detection using TensorFlow

This project implements a **Landmark Detection system** that identifies famous buildings and landmarks from images using **TensorFlow**.

The project is developed as a learning-focused implementation to understand how deep learning models can recognize landmarks and architectural structures from visual data.

---

## 📌 Project Overview

Landmark detection is an important computer vision task used in applications such as image search, travel platforms, and location-based services.

In this project, a TensorFlow-based model is used to analyze an input image and predict the landmark present in the image. The complete inference workflow is implemented inside a Jupyter Notebook.

---

## 🛠️ Technologies Used

- Python  
- TensorFlow  
- TensorFlow Hub  
- NumPy  
- Matplotlib  
- Google Colab / Jupyter Notebook  

---

## 📁 Dataset

This project works with **landmark images** provided as input by the user.

The model is designed to perform inference using pre-trained knowledge and does not require manual training on a custom dataset for basic usage.

Images of landmarks and famous buildings can be obtained from:
- Public image sources
- Open landmark image datasets
- Personal image collections (for testing)

The dataset is used strictly for educational and learning purposes.

---

## ⚙️ Workflow

1. Load the TensorFlow landmark detection model  
2. Upload and preprocess the input image  
3. Perform landmark prediction using the model  
4. Analyze prediction results  
5. Display the predicted landmark
